# Термины по мере обучения

| Термин | Простое объяснение | Где видно в проекте |
|---|---|---|
| Payload | Тело запроса или ответа | response.json() в lab01 |
| Contract / schema | Какие поля и значения принимаем | Модели Pydantic в lab02 |
| Validation | Проверка данных по контракту | ProviderResponse.model_validate |
| Normalization | Перевод ответа провайдера в нашу схему | normalize_response |
| Ingestion | Приём данных в систему | Запрос, проверка, создание события |
| Logical request | Одна пользовательская операция | logical_request_id |
| Attempt | Одно физическое обращение к провайдеру | attempt_id в lab03 |
| Retry | Повторное обращение после сбоя | call_with_retry |
| Backoff | Увеличение ожидания перед повтором | wait(0.1 * 2 ** ...) |
| Jitter | Случайная добавка или разброс ожидания | Пока упражнение в lab03 |
| Idempotency | Повтор операции не меняет итог относительно одного выполнения | Пока не реализована |
| Deduplication | Удаление/предотвращение повторного учёта записи | Пока не реализована |
| Reconciliation | Сверка наших данных с другим источником | Будущий billing-кейс |
| JSONL | Одна запись JSON на строку | data/local/usage.jsonl |
| Trace / span | Связанный путь операции / один её шаг | Обсуждались, в коде пока нет |
| Sampling | Сохранение только части наблюдений | Причина не считать traces полным журналом расходов |

Термины в этой таблице не означают, что соответствующий навык уже освоен.
